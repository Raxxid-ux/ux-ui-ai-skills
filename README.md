# UX/UI Design Skills for AI Assistants

A set of 10 SKILL.md files that teach AI assistants (Claude, Gemini, or any tool that reads plain instructions) how to help with UI/UX design work — research synthesis, Figma workflow, design critique, project planning, and typography/color fundamentals.

Each topic has two versions:
- **Beginner** — step-by-step, explained simply, good for learning or when you want a clear starting process
- **Intermediate** — assumes the basics, adds rigor, edge-case thinking, and systems-level judgment

## What's inside

| Folder | What it helps with |
|---|---|
| `ux-research/` | Turning raw research (notes, interviews, surveys) into real insights |
| `figma-ui/` | Building UI screens and components in a clean, structured order |
| `design-critique/` | Giving and receiving honest, structured design feedback |
| `project-planning/` | Breaking a design project into manageable phases |
| `design-fundamentals/` | Typography and color decisions for UI and branding |

## How to use these

**With Claude:** Add the SKILL.md content as a custom skill in your account (Settings → Capabilities → Skills), or paste the content directly into a conversation when you want that behavior.

**With Gemini:** Paste the SKILL.md content into Gemini's custom skill creation flow.

**With any AI tool:** Paste the file content at the start of a conversation as context — it works as instructions even without a formal "skills" feature.

**Without AI at all:** Every file is also just a solid, readable checklist you can use manually.

## Format

Each file follows the same structure:
- A short description of when to use it
- Step-by-step instructions
- Common mistakes to avoid
- A checklist at the end
